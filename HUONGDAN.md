# Cap nhat bai moi (moi lan)
1. Nhan Claude: "cap nhat" -> tai file `bai_moi.json` ve (vao Downloads).
2. Bam dup bieu tuong **CAP NHAT** tren Desktop (hoac `CAPNHAT.bat`).
3. Thay chu XONG -> doi 1-2 phut, mo app la co bai moi.

# Neu loi
- "Chua cai Git" -> cai Git for Windows (git-scm.com/download/win), bam lai.
- "Khong thay file" -> chua tai bai_moi.json ve Downloads.
- Chu LOI mau do khac -> chup man hinh gui Claude.
- Vao GitHub > tab Actions: dau X do = file bai bi loi (file nam trong thu muc `loi/`), nhan Claude de sua.
